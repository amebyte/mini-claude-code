EP.12 · 为什么需要 cat -n
DEEP DIVE · 设计动机
为什么读取文本后，还要做 cat -n 格式化？
购物清单.txt (raw)
鸡蛋 牛奶 面包 苹果 $
→
cat -n
cat -n 格式化
1→鸡蛋 2→牛奶 3→面包 4→苹果 $
找第三行？左侧要 逐个计数，右侧 3→面包 一眼锁定 ✓
读取时带编号，编辑时取内容。
cat -n 是连接「读取」与「编辑」的契约：结构化数字前缀把模型注意力强制引导到文本物理位置，大幅降低复制粘贴导致的缩进错误与匹配失败。
① 标尺
AI 知道每句话的确切位置；输出时不会带上编号前缀。
② 分页
大文件分页读取，绝对行号让中段片段也知具体位置。
③ 缩进
复制 → 后内容，保留 Python / YAML 缩进，避免匹配失败。
