01

02
查找 Git 安装路径

SUMMARY

总结：两条设计主线

LINE 01
统一的执行入口
无论底层平台如何，都通过 child_process.execFile 调用系统自带的 bash / zsh 运行命令，保证执行行为的一致性
execFile → bash -c <command>
LINE 02
智能的跨平台Shell路径定位
Windows 依赖 Git-Bash 并配合多种查找策略；Unix-like 借助 $SHELL + which；再辅以用户自定义与预置路径兜底，覆盖各种运行环境
Git-Bash · $SHELL · which · fallback[]
